# Workspace commands

```sh
pnpm install
pnpm dev
pnpm dev:generator
pnpm build
pnpm check-types
pnpm test
pnpm outdated -r
pnpm audit
```

To generate website content, run `pnpm dev:generator`, open `http://localhost:5174` in Chrome or Edge, select the game root and this repository's `apps/web` folder, then generate. See [README.md](README.md) for input folders, output paths, and deployment instructions.
